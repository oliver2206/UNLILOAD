# Unli Load Promos (Vite + React)

Easy start:
- Windows: double-click `start.bat`
- Mac/Linux: run `./start.sh`

Or manually:

    npm install
    npm run dev

Edit promos in `src/data/promos.js` (Globe, Smart, TNT, GOMO, TM, Cignal, DITO; pay via GCash, Maya, MariBank, SariPay; Smart promos from SariPay screenshots are included).
Needs Node.js: https://nodejs.org
